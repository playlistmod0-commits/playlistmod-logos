# PlayListMod channel logos

High-resolution logo catalogue for PlayListMod editors, with channel names and aliases.

The current catalogue replaces the earlier provider thumbnails. Original PNG files are stored without resizing or recompression. See [ATTRIBUTION.md](ATTRIBUTION.md) and [UPSTREAM-README.md](UPSTREAM-README.md) for source and usage terms.

`catalog.json` provides relative paths, SHA256, dimensions, names and aliases. Do not use a Git commit from the old thumbnail catalogue for new images. Historical revisions are kept by Git.
